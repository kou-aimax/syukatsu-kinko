# 就活マイページ金庫

企業ごとのマイページ情報・選考状況・初任給の比較、ESの回答ストックと通過率、授業やバイトも入るカレンダーをまとめた就活アプリ。

## 設計の方針
- サーバーを持たない。処理はすべて使う人の端末で行う
- データは使う人のGoogleドライブに保存する（予定）。運営者はデータを見られない
- 現在はテスト版で、データはブラウザ（localStorage）に保存している

## 構成
- `public/index.html`：アプリ本体（HTML・CSS・JavaScriptを1ファイルに収めている）
- `wrangler.jsonc`：Cloudflare Workers の設定
- 公開先：Cloudflare Workers（静的サイトとして配信）

## 料金
- 無料版：企業10社まで
- 有料版（就活シーズンの買い切り）：11社目から無制限（準備中）
